# Dataset Instructions

This project uses the Bank Account Fraud (BAF) Dataset Suite introduced by Jesus et al. (2022).

The original CSV files are not included in this repository because of their large file sizes.

**Download the dataset from Kaggle:**
https://www.kaggle.com/datasets/sgpjesus/bank-account-fraud-dataset-neurips-2022

Download and extract the dataset, then place the required Base and Variant I CSV files in this directory. Update the file paths in the notebook if your filenames differ.

Please review the dataset's licence and the original authors' documentation before redistributing the data.

**Research paper:** https://arxiv.org/abs/2211.13358

**Original dataset documentation:** https://github.com/feedzai/bank-account-fraud
